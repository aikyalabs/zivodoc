Demo: zivodoc chat widget

Bottom-right floating bubble → click to open.

To embed in any docs site, drop one tag: 

<script
  src="https://cdn.zivodoc.com/chat.js"
  data-project="proj_xxx"
  data-title="Ask the docs"
  data-greeting="Hi! I can answer questions about our API."
  data-theme="auto"
  defer></script>

Configuration

  • data-project — required, the project ULID
  • data-api — override API URL (defaults to api.zivodoc.com)
  • data-title — header text
  • data-greeting — first-load message
  • data-theme — auto, light, or dark
  • data-accent — CSS color for primary button (e.g. #7c3aed)
  • data-position — bottom-right (default) or bottom-left
